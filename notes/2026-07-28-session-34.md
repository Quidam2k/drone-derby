# Session 34 — 2026-07-28 — Phase 34: Pushers

Fifth and final rules-parity phase, implemented from the approved plan.
Rules parity with the 1994 set is now complete except option cards
(deliberately cut).

## What shipped

- **Engine**: `PusherDef { pos, facing, registers }` in a new optional
  `BoardDef.pushers` list (mirrors `lasers`; absent = none, zero
  migration). `firePushers(ctx, register)` runs between the all-belts
  pulse and gears; `tryStep` gained a `moverPushed` flag so the shoved
  robot's `robot-moved` carries `pushed: true`. New event
  `pusher-fired { at, dir, player }` — silent when the cell is empty.
  Powered-down robots are shoved (isActive only). Validate: errors for
  bounds/facing/registers (non-empty subset of 1–5)/pit; warning when no
  wall on the mounted edge. Compose offsets pushers like lasers.
- **Built-ins**: The Gauntlet got 3 (corridor pair forcing the lane
  switch on a clock — lane 5 → 6 on 1/3/5, 6 → 5 on 2/4 — plus a west
  safe-lane squeeze at (1,4)); dockyard got 2 baffle pushers (Grand
  Circuit inherits via compose). Proving Grounds untouched; golden
  EventLog snapshot byte-identical.
- **Presentation**: caption "Pusher shoves {player}" (450 ms), audio
  'thud', visualState no-op, director interest 0.5 + both shove ends,
  3D reuses `effects.bump`. DOM `PusherSprite` (wall housing with
  readable "1 3 5"/"2 4", amber vs steel-blue plate), `bump-flash` also
  keys off pusher-fired, BoardThumb free via shared cell maps. 3D kit
  pieces `pusher_housing`/`pusher_plate` in tiles.py (regenerated
  tiles.glb, CPU); plates keep code materials (register schedule is a
  game rule → two tint batches); flat-box primitive fallbacks.
- **Editor**: pusher edge tool with a 1/3/5 ↔ 2/4 option row;
  same-mount same-variant removes, different variant replaces;
  eraseEdge + resizeBoard cover pushers.
- **Docs**: mechanics doc (Board Elements + Cut-from-MVP), rules screen
  legend + resolution order, README checklist, CLAUDE.md scope line.
