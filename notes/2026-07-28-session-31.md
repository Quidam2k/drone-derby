# Session — 2026-07-28 (Phase 31: curved conveyors)

## What shipped

The 1994 curve rule: a robot the belt carries onto a curved section
rotates 90° with the bend. Full details in the cascade's Phase 31 entry
(`cascades/2026-07-05-v2-rewrite.md`); this note is the session trail.

- **Tile shape**: `curve?: 'cw' | 'ccw'` on the existing conveyor tile,
  `dir` still the exit. Entry direction derived
  (`rotate(dir, cw ? -1 : +1)`), never stored. No new tile kind — every
  `kind` switch survived untouched, typecheck drove the rest.
- **Trigger is structural**: rotation happens inside `conveyorPulse`
  only, after a surviving proposal lands, and only when the proposal's
  travel dir equals the curve's entry dir. Cards, pushes, respawns never
  reach that code path, so "only the belt rotates you" needed no flags.
- **Boards**: Spin Cycle + Vortex ring corners all cw; Gauntlet (9,7) cw,
  (10,7) ccw. Proving Grounds untouched → golden snapshot byte-identical
  (verified by the suite, no re-bake).
- **DOM sprite**: quarter-annulus arc in a canonical exit-N cw frame,
  ccw mirrored via `matrix(-1 0 0 1 52 0)`, rotated per exit dir like the
  straight sprite. Chevrons sit ON the arc and march as a staggered
  opacity wave (new `conveyor-march` keyframes) — no transform-origin
  gymnastics. Gotcha: `useId` had to move above the curve early-return
  (conditional hook when a tile flips straight↔curved in the editor).
- **3D**: one `conveyor_curve` kit piece (Blender: bed/rails/rollers
  swept as rotated segments around the corner, radii matching the
  straight bed). The bed is direction-agnostic, so cw yaws by exit dir
  and ccw yaws by `rotate(dir, -1)` — its two open edges land on
  entry/exit either way. Chevrons ride a two-leg path in `tick()`
  (`Chevron.dir2`/`yaw2`, yaw switch at the tile centre). tiles.glb
  re-exported (headless, CPU).
- **Editor**: Straight / ↺ left / ↻ right row; straight paints stay
  curve-less so the JSON-compare dedupe and built-in tiles deep-equal.
- **Tests**: 352 green. New `engine/__tests__/curves.test.ts` (8 cases);
  extended validate/compose/visualState (Spin Cycle full-game lockstep
  now counts real bends)/eventPresentation/directorMath/audio lists.
  directorTurn's measured camera bars held without retuning.
