# 2026-07-28 — Phase 29c: shared deck (board-game rule)

Follow-through on the open question from the scoping session
(`2026-07-28-rules-parity-scoping.md`): Todd decided **match the physical
game — one shared 84-card deck**, reshuffled from the shared discard pile
when the draw pile runs dry. Landed before Phase 30 so the conservation
tests only get rewritten once.

## What changed

- `engine/types.ts` — `PlayerDeck` → `Deck`; `GameState.decks:
  Record<PlayerId, PlayerDeck>` → `deck: Deck`. Card ids are now globally
  unique (every private deck used to contain the same 84 ids).
- `setup.ts` — one `shuffle(buildDeck(), rng)` for the whole game.
- `deck.ts` — `dealHands` draws everyone from `state.deck` in seat order
  (deterministic; with ≤9 players a full deal can't run dry, 9 × 9 ≤ 84);
  `discardHand` → shared pile. `drawCards` untouched — its reshuffle logic
  was already pile-shape-agnostic.
- `execute.ts` `cleanUpCards` — dropped the `player in s.decks` guard
  (existed for redacted preview states); all discards go to the shared
  pile. killRobot already clears `lockedRegisters`, so eliminated players'
  cards return to the pool for free.
- `preview.ts` — `deck: state.deck ?? { drawPile: [], discardPile: [] }`
  for redacted online states.
- `convex/games.ts` `sanitizeState` — `deck: { drawPile: [],
  discardPile: [] }` instead of `decks: {}` (+ comment sweeps in
  schema.ts, OnlineGameScreen.tsx).

## Tests (the real work)

- `invariants.test.ts` — conservation is now **global and stronger**:
  drawPile + discardPile + Σ hands + Σ lockedRegisters = 84 with all ids
  unique across the whole game, checked before the per-robot loop (the
  `final` early-return now skips only the between-turns checks).
- `determinism.test.ts` — multi-turn smoke sums globally; the golden
  EventLog snapshot was legitimately re-baked (same seed now deals
  different hands — one deck, interleaved deal).
- `deck.test.ts` — createGame leaves 84 − 18 = 66 in the draw pile, hands
  disjoint from it; **new `shared-deck scarcity` suite**: 6 players on an
  empty 12×12 deal 54/84 per turn, so every second deal runs the pile dry
  → asserts the reshuffle emptied the shared discard pile after turn 1,
  conservation through it, and 4-turn determinism (two runs deep-equal).
- `preview.test.ts` — redacted state is `deck: { drawPile: [],
  discardPile: [] }` now.
- **327 tests + typecheck green.**

## Compatibility call

In-flight online games persisted with the old `decks` shape will throw at
their next turn execution. **No migration, on purpose**: replays are
EventLog-driven and unaffected, prod is pre-playtest, and the prod deploy
is gated on the 3D-5/6/7 look gates anyway. Fresh games are fine.
