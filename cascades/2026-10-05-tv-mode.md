# Cascade: TV mode + turn timer (Jackbox-style couch play)
Started: 2026-10-05

Goal: a TV shows the shared board and plays each turn while players program on
their phones (mixed with remote players), plus a configurable turn timer
(untimed default, 30 s – 7 days). On timeout the official rule applies: empty
registers get random cards from the player's hand.

The diagnosability cascade's P5 hard stop is unaffected by this cascade.

## Cross-phase decisions
- Timer counts from turn start (not the 1994 sand-timer).
- Timeout fill: `autoFillProgram(hand, damage, partial, rng)` in
  `src/engine/deck.ts`, seed `game.seed + turn * 7919 + seat`.
- TV viewer is unauthenticated; the invite code is the key (`tvGame`,
  `tvTurn` queries return `sanitizeState(state, null)` only).
- Controller mode is a per-player phone toggle (`viewSettings.controllerMode`).
- No prod deploy without asking Todd.
